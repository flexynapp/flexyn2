What the audit established

01

Nothing changed, and nothing was written.

No code modified, no migration, no production row touched. The harness under harness/ is a read-only render rig and every query was a SELECT.

02

The mechanism is sound on every path that was tested.

Slots render, the sheet opens, the write persists, and checkUserAuth() makes the banner crest and the signature list move without a reload — the fix its own comment at :867 describes still holds.

03

Privacy works. The case obeys its flag and takes the crest with it.

With trophy_case_visible = false a stranger sees no case section at all, and the banner drops the crest on the same flag. Rendered and confirmed. Note that 0 of 63 profiles are private, so that branch has never once run in production.

04

The picker cannot be constrained to earned trophies today, because it never knew about them.

The emoji list is a literal array inside a 2,400-line component. It shares no import, no type and no id space with user_trophies. Connecting them is new work, not a filter.

05

The feature downstream of it has never been used once.

signature_trophy pins a case emoji next to your name in the feed. It is set on 0 of 63 profiles — which is what you would expect of a reward for a decision only two people have made.

06

Five English literals sit inside a component whose labels are all translated.

"Choose Trophy", "Remove", "Signature trophy", "Tap the active one to remove it." and the failure toast. Every slot aria-label around them goes through tFallback. Do not machine-translate — standing rule.

07

The write is legitimate, and that was checked rather than assumed.

trophy_case is correctly absent from migration 142’s immutable column list. Verified against the installed triggers on user_profiles, not against the migration file.

08

Recommendation: this is a product call, and it comes before the other three.

Rename it (free), constrain the picker to earned emoji, or replace it with five pinned collection tiles. Only the third makes the banner crest mean anything. Options two and three make the case a second reader of the count that graphic 02 is about — so fix that first.
