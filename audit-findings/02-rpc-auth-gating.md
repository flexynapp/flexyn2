# Audit: SECURITY DEFINER RPC auth-gating

Scope: every `CREATE OR REPLACE FUNCTION ... SECURITY DEFINER` across
`C:/Flexyn/supabase/migrations/*.sql`. Each row is a function where a
client-supplied user identifier (or other privileged param) reaches a
write/read without the function first checking it against
`auth.uid()` / `auth.email()` / `public.is_app_admin(auth.uid())`.

## Summary statistics

- **Critical**: 3 (broken: `grant_flex_coins`, `record_monthly_xp`; latent footgun: `006` blanket `GRANT ... TO anon`)
- **High**: 5 (capsule-claim trust, achievement-milestone trust, notification-fanout phishing — 2 RPCs, privileged-column trigger gap)
- **Medium**: 9 (mostly defense-in-depth + DM/group spam vectors + rate-limit gaps)
- **Low**: 8 (style, plus confirmed-clean RPCs included for transparency)

## Top 3 to land first

1. **`grant_flex_coins`** — revoke `authenticated` execute or inline into `claim_referral`. Production economy is currently mintable by any authenticated user. Same defect class as the patched-by-042 `increment_user_xp`, just no follow-up.
2. **`record_monthly_xp`** — derive caller from `auth.uid()`, cap `p_amount`. Monthly league rank is currently a self-set field.
3. **`finalize_capsule_claim`** — read item details from the persisted capsule roll, not the client. Capsule rarity is currently a client-asserted field after the roll completes.
